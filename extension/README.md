# PAVENRO Focus Job Capture

Free Chrome/Edge extension for transferring a visible job posting into PAVENRO Focus.

## Install

1. Download and unzip `pavenro-focus-job-capture.zip`.
2. Open `chrome://extensions` or `edge://extensions`.
3. Enable **Developer mode**.
4. Select **Load unpacked** and choose the extracted `extension` folder.

Open a full LinkedIn, Indeed, Naukri or company career-page posting, click the extension, then select **Capture job**. PAVENRO Focus opens a review form; verify the captured fields before saving.

After installing or updating the extension, reload any job tab that was already open. Version 1.2.0 supports the PAVENRO Focus Cloudflare beta and retains the legacy GitHub Pages handoff during migration.

The extension has no paid service, server or analytics. It only reads the active page after you click Capture and uses browser storage briefly to transfer the draft.
